# User Stories

## Epic 1: Profile & Verified Skill Management
- **US-101:** As a job seeker, I want to record my verified technical skills and experience levels so that AI resume tools only use factual capabilities.
- **US-102:** As a job seeker, I want to categorize skills into production vs. personal project experience so that tailored resumes reflect accurate career depth.

## Epic 2: Job Ingestion & AI Fit Analysis
- **US-201:** As a candidate, I want to paste a job description or URL so that the system extracts requirements and detects duplicates automatically.
- **US-202:** As a candidate, I want to view a 0-100 fit score and skill gap breakdown so that I know whether an opportunity is worth my time.

## Epic 3: Truthful Resume Tailoring
- **US-301:** As a candidate, I want the system to generate a tailored resume prioritizing matching skills so that my application passes recruiter screening.
- **US-302:** As a candidate, I want to review and edit the generated resume before export so that I maintain 100% personal ownership of submitted documents.

## Epic 4: Email Synchronization & Automation
- **US-401:** As a candidate, I want the system to sync my job-related emails so that interview invites and OA deadlines are detected automatically.
- **US-402:** As a candidate, I want AI to draft polite recruiter replies so that I can respond quickly after reviewing the draft in the approval queue.

## Epic 5: Interview Prep & Analytics
- **US-501:** As a candidate, I want an automated preparation dossier generated for upcoming technical interviews so that I can review relevant projects and topics.
- **US-502:** As a candidate, I want to view my funnel metrics (Applied -> Interview -> Offer) so that I can optimize my application strategy.
